# ARBIFY PULSE 3.0 — українська версія

Повний статичний проєкт для GitHub Pages.

## Що додано у версії 3.0

- головна сторінка `home.html`;
- автоматичний перехід після правильного ключа;
- єдиний ключ доступу `K7X4Q9`;
- меню «Головна / Сигнали / Бонуси / Профіль»;
- три оригінальні обкладинки слотів;
- вибір гри та анімація запуску сигналу;
- адаптація під телефон і комп’ютер.

## Структура

```text
ARBIFY-PULSE-3.0/
```

## Запуск

Відкрий `index.html` та введи ключ `K7X4Q9`. Після перевірки сторінка
автоматично відкриє `home.html`.

## GitHub

Перенеси весь вміст папки `ARBIFY-PULSE-3.0` у корінь репозиторію та натисни
**Commit changes**.

## Важливо

На статичному сайті ключ зберігається у браузерному JavaScript і не є повністю
захищеним. Для справжньої безпечної авторизації потрібні сервер, база ключів та
API. Розділи «Сигнали», «Бонуси» й «Профіль» поки показують повідомлення —
їхні окремі сторінки створюватимуться наступними етапами.
