# ARBIFY PULSE 2.0 — українська версія

Готовий статичний перший екран для завантаження на GitHub. У версії 2.0
додані анімації інтерфейсу, покращена мобільна адаптація, Telegram-підтримка
та демонстраційна перевірка ключа.

## Структура

```text
ARBIFY-PULSE-2.0/
├── index.html
├── style.css
├── effects.css
├── script.js
├── README.md
└── assets/
    ├── arbify-pulse-hero-v2.webp
    └── favicon.svg
```

## Як запустити

Відкрий `index.html` у браузері. Для тесту введи будь-який ключ довжиною від
6 символів, наприклад `PULSE-2026`.

Перед публікацією відкрий `script.js` і заміни `YOUR_USERNAME` у рядку
`const TELEGRAM_USERNAME = "YOUR_USERNAME";` на username менеджера без `@`.

## Як завантажити на GitHub

1. Створи новий репозиторій, наприклад `arbify-pulse`.
2. Натисни **Add file → Upload files**.
3. Завантаж усі файли й папку `assets`.
4. Натисни **Commit changes**.
5. Для безкоштовної публікації відкрий **Settings → Pages**.
6. У **Build and deployment** вибери **Deploy from a branch**.
7. Вибери гілку `main`, папку `/root` і натисни **Save**.

Через кілька хвилин GitHub покаже посилання на сайт.

## Важливо

Поточна перевірка ключа — демонстраційна і працює в браузері. Для справжнього
закритого доступу ключі не можна зберігати в `script.js`: потрібні сервер,
база даних та API. Це можна підключити на наступному етапі.
